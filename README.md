## 🚀 Featured Projects

### 📅 Modsen Calendar
A responsive calendar SPA built with **React, TypeScript, Vite and dnd-kit**. Supports day/week views, drag-and-drop event rescheduling, full CRUD, Ticketmaster API search, and localStorage persistence. Includes custom hooks, Context, ErrorBoundary and a fully modular SCSS architecture.

`React` `TypeScript` `Vite` `dnd-kit` `Axios` `SCSS`

[→ View on GitHub](https://github.com/ppl0l/modsen-practice11)

### 🍔 Food Delivery App
A cross-platform mobile app built with **React Native + Expo**. Features Firebase authentication, Firestore sync, offline-first SQLite cache, Cloudinary image uploads, dark/light theme, i18n (RU/EN), and local notifications. Follows an MVVM-style architecture with ViewModels and Services.

`React Native` `Expo` `Firebase` `SQLite` `Cloudinary` `MVVM`

[→ View on GitHub](https://github.com/ppl0l/MobileApp)

### 🎬 CineTrack
A movie & series watchlist app implemented in **two versions**: an SSR app on Express + EJS, and a React SPA with SSR hydration (ReactDOMServer + hydrateRoot). Supports poster uploads via Multer, filtering by status, UUID-based IDs and full validation.

`React` `Express` `EJS` `SSR` `Webpack` `Multer`

[→ View on GitHub](https://github.com/ppl0l/CineTrack_SPP)

### 💫 Star Laser Glow
A single-page landing website for a beauty salon, built with **React and GSAP**. Features animated hero section, service catalog with prices, YCLIENTS online booking integration, modal windows, smooth scrolling and full responsiveness.

`React` `React Router` `React Bootstrap` `GSAP` `CSS3`

[→ View on GitHub](https://github.com/ppl0l/website_starlaserglow)

### 🎨 Graphic Editor
A **C# / .NET WPF** graphic editor demonstrating core OOP principles: inheritance, polymorphism, abstract classes, interfaces and the Factory pattern. Supports drawing geometric shapes, undo/redo, JSON save/load, and dynamic DLL plugin loading via reflection.

`C#` `WPF` `.NET` `OOP` `Factory Pattern` `Reflection`

[→ View on GitHub](https://github.com/ppl0l/OOP)
